# 💬 Text Analyzer Web App

A simple NLP-based web application built using Streamlit that analyzes user text.

---

## 🚀 Features

- 🧹 Text Cleaning & Preprocessing  
- 🔍 Keyword Extraction  
- 😊 Sentiment Analysis (Positive / Negative / Neutral)  

---

## 🛠️ Tech Stack

- Python  
- Streamlit  
- TextBlob  
- NLTK  

---

## 📂 Project Structure

text-analyzer-app/
│
├── app.py
├── requirements.txt
└── README.md

---

## ▶️ How to Run

1. Clone the repository:
git clone https://github.com/Hamsa1016/text-analyzer-app.git

2. Navigate to the project folder:
cd text-analyzer-app

3. Install dependencies:
pip install -r requirements.txt

4. Run the app:
streamlit run app.py

---

## 💡 Example

Input:
"I am feeling happy today"

Output:
- Keywords: ['feeling', 'happy']
- Sentiment: Positive 😊
